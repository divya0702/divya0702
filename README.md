## Selected projects

**[Green Sense](https://devpost.com/software/green-sense)** — 1st Place, FinTech Track, Gemini Hack Night 2025  
AI sustainability platform that extracts energy and carbon metrics from utility bill PDFs using the Gemini API. RAG-powered chatbot, interactive dashboards, gamified carbon leaderboard.

**[BookMyEvent](https://github.com/divya0702/eks-microservices)**  
Distributed event booking system on AWS EKS. Go microservices, concurrency-safe booking logic, auto-scaling infrastructure, full observability stack. Built to hold up under real traffic.

**[Phishing Email Detection](https://github.com/divya0702/phishing-email-detection)**  
Deep learning models trained on 145,000+ emails. charCNN-BERT architecture achieved 99.0% accuracy and 0.994 F1-score by fusing character-level CNNs with BERT embeddings.

**[Terp EventSphere](https://github.com/divya0702/Terp-EventSphere)**  
Microservices campus events platform. React frontend, Node.js backend, PostgreSQL on NeonDB. Modular services for discovery, registration, and waitlist management.

**OCR Manuscript Pipeline** *(UMD Research)*  
TrOCR + PyTorch pipeline digitizing 18th-century manuscripts. 60% reduction in manual correction effort. Part of a broader digital humanities platform with GIS maps and 3D visualization.
